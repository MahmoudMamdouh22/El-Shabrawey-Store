# الشبراوي ستور — EL-Shabrawey Store

متجر إلكترونيات وكمبيوتر باللغة العربية والإنجليزية، مبني باستخدام Next.js وPrisma وSQLite.

## تشغيل المشروع محليًا

1. ثبّت اعتماديات المشروع باستخدام `npm install`.
2. جهّز متغيرات البيئة لقاعدة البيانات وحساب الإدارة.
3. شغّل الترحيلات باستخدام `npx prisma migrate deploy`.
4. شغّل `npm run dev` وافتح `http://localhost:3001`.

## إعداد حساب الإدارة

قبل تشغيل `npm run db:seed`، عيّن `ADMIN_EMAIL` و`ADMIN_PASSWORD` في ملف البيئة المحلي. لا توجد بيانات دخول افتراضية مضمنة في المستودع.

## صفحات ووظائف المتجر الحالية

- عرض المنتجات وصفحات تفاصيل المنتج والسلة وإتمام الطلب.
- تسجيل الدخول وحساب العميل ولوحة الإدارة.
- إدارة المنتجات والطلبات والإعدادات.
- تتبع الطلبات برقم يبدأ بـ `ESH-`.
- إعدادات بكسلات التسويق وعرض المنتج الإضافي في الدفع.
- صفحة سياسة الشحن والضمان والاستبدال.

المنتجات الفعلية تُضاف من لوحة الإدارة؛ لا يضيف seed منتجات تجريبية.
