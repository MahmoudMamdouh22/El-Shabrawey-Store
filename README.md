# الشبراوي ستور — EL-Shabrawey Store

متجر إلكترونيات وكمبيوتر بواجهة عربية RTL، مبني باستخدام Next.js وPrisma وTurso (libSQL).

## تشغيل المشروع محليًا

1. ثبّت الاعتماديات باستخدام `npm install`.
2. انسخ `.env.example` إلى `.env` وأدخل `TURSO_DATABASE_URL` و`TURSO_AUTH_TOKEN` و`AUTH_SECRET` الخاصة ببيئة التطوير.
3. تأكد من تطبيق مخطط الجداول على قاعدة Turso التجريبية قبل تشغيل التطبيق.
4. شغّل `npm run dev` وافتح `http://localhost:3000`.

## إعداد حساب الإدارة

قبل تشغيل `npm run db:seed`، عيّن `ADMIN_EMAIL` و`ADMIN_PASSWORD` وبيانات Turso في ملف البيئة المحلي. أمر seed يتصل بقاعدة Turso المحددة؛ لا تشغّله على قاعدة الإنتاج إلا إذا كنت تقصد ذلك.

## صفحات ووظائف المتجر الحالية

- عرض المنتجات وصفحات تفاصيل المنتج والسلة وإتمام الطلب.
- تسجيل الدخول وحساب العميل ولوحة الإدارة.
- إدارة المنتجات والطلبات والإعدادات.
- تتبع الطلبات برقم يبدأ بـ `ESH-`.
- إعدادات بكسلات التسويق وعرض المنتج الإضافي في الدفع.
- صفحة سياسة الشحن والضمان والاستبدال.

التطبيق لا يستخدم SQLite محلية كـfallback؛ يلزم إعداد Turso محليًا وعلى Netlify. عينات المنتجات التي ينشئها seed موسومة بوضوح كبيانات تجريبية ولا تصلح للبيع.
